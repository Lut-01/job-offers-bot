\# Job Offers Bot



Bot de veille automatisée qui recherche des offres d'alternance en informatique et envoie une notification Discord dès qu'une nouvelle offre correspondant à mes critères apparaît.



\## Fonctionnalités



\- Recherche sur plusieurs mots-clés et départements via l'API officielle France Travail

\- Filtre automatique sur les offres en alternance

\- Détection des nouvelles offres (pas de doublons entre deux exécutions)

\- Notifications automatiques sur Discord



\## Stack technique



\- Python

\- API France Travail (OAuth2)

\- Webhooks Discord
